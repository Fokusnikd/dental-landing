# Стоматология «Эмаль» — демо-лендинг

Демо-проект для портфолио: одностраничный сайт стоматологической клиники. Клиника вымышленная, имена, цены и отзывы придуманы, форма никуда не отправляет данные.

## Что внутри

- Адаптивная вёрстка от 360 px до широких экранов
- Калькулятор стоимости: вопросы меняются в зависимости от ответа, результат подставляется в форму записи
- Табы с ценами по направлениям, управление с клавиатуры (стрелки)
- Форма записи: маска телефона, валидация, состояние «заявка отправлена»
- FAQ на нативных `<details>`, мобильное меню, плавная прокрутка с учётом `prefers-reduced-motion`
- Собственный набор SVG-иконок и иллюстраций, без сторонних картинок
- Lighthouse (mobile): Accessibility 100, Best Practices 100, SEO 100 — контраст по WCAG AA, корректные ARIA-роли, видимый фокус

## Стек

React 19, TypeScript, Tailwind CSS 4, Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`. Сборка использует относительные пути, поэтому её можно выложить в любую папку, например на GitHub Pages.
